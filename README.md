# Vinyl Collection Manager

Personal tool to catalogue vinyl records using album cover photos.

Album covers are identified via Claude's vision API (single images, bulk local
files, or via a Telegram bot). Cover art comes from MusicBrainz / Cover Art
Archive, and tracklists are generated by Claude. Data is stored in a local
SQLite file. A small FastAPI web app provides a basic UI.

## Requirements

- Anthropic API key
- Telegram bot token (from @BotFather)
- Optional: VPS with Nginx / Nginx Proxy Manager

## Setup

1. Clone the repo
   ```
   git clone https://github.com/peteD900/vinyl-recorder.git
   cd vinyl-recorder
   ```

2. Create a Telegram bot via @BotFather and save the token.

3. Create a `.env` file:
   ```
   APP_ENV=test
   ANTHROPIC_API_KEY=sk-ant-...
   BOT_TOKEN=prod_bot_token
   BOT_TOKEN_TEST=test_bot_token
   ```

   `APP_ENV=test` uses a separate DB file, a separate bot token, and a
   separate images directory from prod so your laptop experiments never
   touch real data.

## Run Locally

Docker:
```
docker-compose up
```

Web UI: http://localhost:8001

Without Docker:
```
uv sync
uvicorn vinyl_recorder.web_app:app --reload --port 8001
python vinyl_recorder/telegram_bot.py
```

## Production (VPS)

```
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

Use Nginx / Nginx Proxy Manager to forward traffic to the web container
(port 8000) and enable SSL.

## Usage

Telegram:
- Send an album cover photo to the bot, confirm, add to collection
- `/recommend` — get album suggestions based on your collection
- `/tobuy` — add an album to your wishlist (freeform text, LLM verifies)
- `/buylist` — show your wishlist
- `/bought <n>` — remove item N from your wishlist

Bulk (local files):
- Set image path in config
- Run: `python scripts/run_bulk_identification.py`

## Environments

| APP_ENV | DB file | Images dir | Bot token |
|---------|-----|---|---|
| prod    | `data/vinyl_collection.db`       | `data/all_images`  | `BOT_TOKEN` |
| test    | `data/vinyl_collection_test.db`  | `data/test_images` | `BOT_TOKEN_TEST` |

The prod DB is tracked in git; the test DB and test images are gitignored.

## Notes

- Only one Telegram bot instance can run at a time
